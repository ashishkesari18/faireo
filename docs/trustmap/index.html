How does cropland model performance vary by country?

Each country was held out of training, then scored against ground labels from NASA Harvest's CropHarvest. The trust estimate uses unlabeled target-country features and outcomes from other benchmark countries. Measured countries display leave-one-country-out scores; sparse-country estimates have not been independently validated.

AUC: how well the model ranks crop above non-crop (0.5 = chance, 1 = perfect). Measured only where a country has at least 100 labelled points with 20 of each class (66 countries). Trust score: internal leave-one-country-out prediction of benchmark AUC using model confidence and AUC in similar countries (Presto embeddings), not a deployment guarantee. Sample crop-prevalence error: predicted-positive fraction minus observed crop fraction among labeled points (percentage points); not national cropland-area error.

Data: CropHarvest v0.7 (Tseng et al., 2021), Sentinel-1/2, ERA5, SRTM. Borders: Natural Earth. Income groups: World Bank classification as recorded in Natural Earth.
